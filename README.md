# 💊 MedFinder

**MedFinder** is a digital solution designed to help users locate nearby pharmacies, search for essential medicines, and manage their health needs efficiently. 

---

## 🚀 Key Features

* **Pharmacy Locator**: Find medical stores near your current location.
* **Medicine Search**: Search for prescribed drugs or active ingredients.
* **Smart Reminders**: Schedule timely alarms for daily medications.
* **Health Trackers**: Quick tools to calculate key health metrics like BMI.

---

## 🛠️ Tech Stack

* **Frontend**: React / Android Studio (Java/Kotlin) / Flutter 
* **APIs**: Google Maps API, RxNorm Medicine API

---

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com
   cd MedFinder
   ```

2. **Install dependencies**
   ```bash
   npm install   # For web projects
   # OR use the appropriate command for your environment (e.g., flutter pub get)
   ```

3. **Configure Environment Variables**
   Create a `.env` file in the root directory and add your secret keys:
   ```env
   MAPS_API_KEY=your_key_here
   MEDICINE_API_KEY=your_key_here
   ```

4. **Run the application**
   ```bash
   npm start
   ```
